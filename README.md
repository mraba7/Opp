# موقعي للمندوب

تطبيق أندرويد بسيط: تحفظ عنوانك وصورة منزلك مرة واحدة، وبعدها بضغطة زر واحدة يرسل الاثنين مباشرة لمحادثة واتساب مع المندوب.

## طريقة البناء (نفس أسلوب مشروع الـ IPTV)

1. ارفع هذا المجلد كامل إلى مستودع جديد على GitHub (أو داخل مستودع `mraba7/me` في مجلد فرعي).
2. بمجرد ما ترفعه، GitHub Actions بيشتغل تلقائياً (الملف: `.github/workflows/build.yml`) ويبني الـ APK في السحابة — ما تحتاج أندرويد ستوديو أو أي تثبيت محلي.
3. روح لتبويب **Actions** في المستودع، افتح آخر تشغيل (run)، وحمّل الملف من قسم **Artifacts** باسم `app-debug-apk`.
4. انزل الملف على جوالك وثبّته (لازم تفعّل "السماح من مصادر غير معروفة" أول مرة).

## المميزات الحالية

- عدة عناوين (بروفايلات) بألوان مختلفة، كل وحدة بتفاصيلها وصورها المستقلة
- رابط قوقل مابس + عنوان وطني + رقم مبنى + مكان وضع الشحنة
- خريطة مصغّرة تلقائية (من OpenStreetMap، مجانية بدون مفتاح API) تظهر فوق التفاصيل
- إرسال كصور وملفات منفصلة، أو كـ"بطاقة" مدمجة (صورة واحدة فيها كل التفاصيل والصور) — تختار من مفتاح داخل التطبيق
- نسخة احتياطية JSON (تصدير/استيراد) لكل العناوين والصور
- سجل آخر 5 عمليات إرسال
- ثيم فاتح/غامق تلقائي حسب إعداد الجهاز
- صوت تأكيد بسيط عند الإرسال

## ملاحظات

- التطبيق يخزن كل البيانات والصور محلياً على الجهاز فقط. الخريطة المصغّرة فقط تحتاج إنترنت (تحميل رقعة خريطة من OpenStreetMap).
- زر "إرسال الموقع" يفتح واتساب مباشرة، وتختار محادثة المندوب يدوياً (واتساب ما يسمح باختيار جهة الاتصال تلقائياً لأسباب أمنية).
- إذا واتساب مو مثبت، يفتح شاشة مشاركة عامة بدلاً منه.

## تحديث التطبيق لاحقاً بدون فقد البيانات

عشان أي تحديث مستقبلي (APK جديد من GitHub Actions) يركب **فوق** النسخة القديمة ويحافظ على كل عناوينك وصورك:
- ثبّت النسخة الجديدة مباشرة فوق القديمة (بدون حذف التطبيق القديم أولاً)
- تأكد إن `applicationId` بملف `app/build.gradle` ما تغيّر (`com.mraba7.deliverylocation`) — هذا هو المعرّف اللي أندرويد يعتمد عليه ليعرف إنها نفس النسخة
- لو حبيت تزيد رقم الإصدار شكلياً، عدّل `versionCode` و`versionName` بنفس الملف قبل كل رفع، بس مو شرط للتحديث العادي

لو احتجت تنقل بياناتك لجهاز جديد بدل التحديث، استخدم زر "⬆️ نسخ احتياطي" ثم "⬇️ استيراد" بالتطبيق على الجهاز الجديد.
